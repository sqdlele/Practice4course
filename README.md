# Чисто.Тут

Веб-приложение для учёта заказов химчистки. Два интерфейса: для **сотрудников** (приём заказов, прайс, чаты) и для **клиентов** (каталог услуг, корзина, личный кабинет, чат с поддержкой).

## Стек

- **Python 3**
- **Django 6**
- SQLite (по умолчанию)


## Маршруты

`/`  Редирект на главную клиентов 
`/c/`  Сайт для клиентов 
`/staff/`  Панель сотрудников 

## Для сотрудников (`/staff/`)

- **Вход** — по телефону (формат 8XXXXXXXXXX или 7XXXXXXXXXX). Регистрация с подтверждением админом (`is_active`).
- **Главный экран** — счётчики «В работе» / «Готово к выдаче», поиск по ID заказа или телефону, блок «Горящие заказы».
- **Новый заказ** — живой поиск клиента по базе, быстрая регистрация (ФИО + телефон), выбор услуг с множителем сложности (1 / 1.3 / 1.5) и при необходимости размеры/вес. Авто-скидка 3% при 2+ выданных заказах у клиента.
- **Чаты** — список чатов с клиентами и просмотр переписки.
- **Прайс** — только у пользователей с правами администратора (редактирование категорий и услуг в `/admin/`).

Модели: пользователь (User с телефоном и отчеством), Client, Order, OrderItem, Service, ServiceCategory, HeroBanner, Review.

## Для клиентов (`/c/`)

- **Главная** — слайдер баннеров, блок «Популярные услуги» (до 6), блоки категорий «Наши услуги» (Одежда, Дом и т.д. с картинкой и списком услуг), Яндекс.Карта, отзывы.
- **Услуги** — каталог категорий (`/c/services/`), страница категории с описанием и ячейками-ссылками на услуги, страница услуги с вариантами и кнопкой «Добавить».
- **Корзина** — хранение в `localStorage`, страница корзины, отправка заявки (для авторизованных) через API. Иконка корзины в шапке (у сотрудников не показывается).
- **Личный кабинет** — профиль (ФИО, телефон, email), редактирование профиля, список своих заказов (по совпадению телефона с клиентом).
- **Чат с поддержкой** — виджет в углу для авторизованных не-сотрудников; ответы видны в панели сотрудников в «Чаты».
- **О нас** — статическая страница о компании.
- **Регистрация/вход** — по телефону, ФИО, отчество обязательно.

Модели чата: ChatRoom, ChatMessage (в приложении `customer`).

## Админка

В админке настраиваются:

- **Пользователи** — активация новых сотрудников (разрешить вход).
- **Категории услуг** — название, slug, изображение, описание (для страницы категории).
- **Услуги** — категория, родительская услуга (для вариантов, например «Пиджак+брюки» у «Деловой костюм»), цена, единица (штука/кг/м²), срок чистки, флаги «нужны размеры/вес», «популярная».
- **Баннеры** главной, **отзывы**, **клиенты**, **заказы**.
